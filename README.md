# ⚡ EasyML Studio - 3-in-1 Prediction Dashboard

An interactive and layman-friendly machine learning dashboard built with **Streamlit**, **Scikit-Learn**, and **Plotly**.

---

## 🌟 Included Models

1. **🩺 Diabetes Risk Checker** (PIMA Indian Diabetes Dataset)
2. **🔬 Breast Tumor Diagnostic AI** (Wisconsin Diagnostic Breast Cancer)
3. **🚗 Used Car Resale Price Calculator** (Quikr Indian Automobile Listings)

---

## 🚀 Quick Start (Local Run)

1. **Activate Virtual Environment:**
   ```powershell
   .\Scripts\activate
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch the App:**
   ```bash
   streamlit run app.py
   ```
   Open `http://localhost:8501` in your browser.

---

## ☁️ 1-Click Deployment on Streamlit Community Cloud (Free)

1. Push this repository to **GitHub**.
2. Go to [share.streamlit.io](https://share.streamlit.io).
3. Connect your GitHub repository.
4. Set:
   - **Main file path:** `app.py`
   - **Branch:** `main` (or `master`)
5. Click **Deploy!** 🎉
